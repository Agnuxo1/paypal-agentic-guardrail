## Scope and reason for this correction

The organisers explicitly requested footage of the project functioning on the
device for which it was developed. The prior animated presentation was replaced
on 11 November 2026 in the original submitted entry. The new video includes
authentic Windows desktop frames recorded while the committed software executed.
Introductory and final graphics are original presentation assets, distinct from
the real screen-captured runtime.

## What the footage demonstrates

1. A real local Node.js payment broker operation: allowed order and capture,
   rejected redirected payee, rejected over-limit payment, replay suppression,
   rejected credential access and an operation awaiting human approval.
2. A 450-execution fixed offline benchmark comparing three arms. The guardrail
   arm rejects 100 out of 100 scripted attacks, with no incidents recorded
   in that arm's fixed test suite.
3. All 70 automated tests pass with zero failures when run on the target device.

These tests are a controlled local reproduction, not an estimate of production
fraud losses or real-world security effectiveness.

## Reproduce on a Windows computer (no account or API credentials required)

Install Node.js 22 or newer, then enter the following commands:

    git clone https://github.com/Agnuxo1/paypal-agentic-guardrail.git
    cd paypal-agentic-guardrail
    npm ci
    npm run demo
    npm run bench
    npm test

The offline mock transport is the default. All payment operations in the
published video use this mock transport; they do not move real money or use
production credentials. Additional operator-console configuration is described
in README.md. The footage proves the local CLI broker execution and should
not be interpreted as demonstrating browser-console authentication.
